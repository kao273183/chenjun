宸鈞數位有限公司（統一編號：62201354，下稱「我們」）尊重並保護所有使用 Rovia Airport 機場接送預約平台（下稱「本平台」）之車隊、司機與乘客之個人資料。本隱私政策（下稱「本政策」）說明我們依《個人資料保護法》及相關法令規定蒐集、處理、利用您個人資料之原則與範圍。請於使用本平台前詳細閱讀本政策。

適用範圍

本政策適用於您使用 Rovia Airport 系列服務時所產生之個人資料處理行為，包含但不限於：

  • 乘客 LIFF（透過 LINE 預約叫車之介面）；
  • 司機 LIFF（司機接單與管理介面）；
  • 車隊後台（車隊管理員之 Web 後台）；
  • Hub 後台（平台方管理介面）；
  • Telegram Bot（司機推播選用通道）。

本政策不適用於與本平台連結之第三方網站、App 或服務（如 LINE、Telegram、Google Maps），其各自之隱私政策由該服務提供者自行訂定。

蒐集目的

我們蒐集您的個人資料，係基於下列特定目的：

  • 提供叫車媒合、訂單管理、派單通知等核心服務；
  • 進行身分驗證、帳號維護與防止冒用；
  • 於配對成立後，使乘客與司機得以聯繫完成運送；
  • 計費、結算、產生報表（車隊後台）；
  • 客戶服務、爭議處理、客訴回應；
  • 系統維運、效能優化、防範濫用與資安事件；
  • 履行法律義務（如稅務申報、配合主管機關調查）；
  • 於取得您個別同意後，發送行銷與優惠資訊。

利用範圍

個人資料之利用，限於上述蒐集目的之必要範圍內，並依下列原則處理：

  • 地區：以中華民國境內之伺服器（Google Firebase asia-east1，台灣機房）為主；
  • 對象：我們的工程與營運人員、所屬車隊、配對成立之司機、必要之第三方服務提供者；
  • 期間：自您加入本平台起至帳號刪除後依法令保留期間屆滿止；
  • 方式：以加密、機房控管、權限管理、日誌稽核等技術措施保護。

資料儲存與保護

6.1 儲存位置

所有資料均儲存於 Google Firebase asia-east1（台灣機房），符合資料境內處理原則。我們未將個人資料移轉至我國境外或大陸地區。

6.2 技術措施

  • 傳輸加密：所有 API 通訊強制使用 HTTPS / TLS 1.2 以上；
  • 儲存加密：Firebase 預設於靜態加密儲存資料；
  • 存取控管：透過 Firestore Security Rules 嚴格限制讀寫權限，乘客僅能讀寫自己的資料、車隊僅能讀寫自家資料；
  • 負面權限：車隊後台支援針對特定子帳號禁止匯出、禁止查看電話等敏感欄位；
  • 金鑰管理：API Key 與第三方憑證使用環境變數與限制原則（如 Google Maps Key 限制 HTTP Referrer）；
  • 日誌稽核：登入、敏感操作均留有可追溯紀錄。

6.3 管理措施

  • 員工依 Need-to-know 原則取得最小必要權限；
  • 新功能上線前進行資安審查；
  • 重大事件發生時依法通知您與主管機關。

資料保留期限

個人資料之保留期限依資料性質與法律要求而異：

  • 帳號基本資料：自註冊起至您主動刪除帳號後，因法令、會計或舉證需要，仍保留適當期間（通常 5 年）；
  • 訂單與付款紀錄：依稅捐稽徵法規定保留至少 5 年；
  • 聊天訊息：與訂單關聯保留同期，獨立刪除帳號可申請另行刪除；
  • 系統日誌：依資安實務保留 90～180 天；
  • 已踢出車隊之司機帳號：採用軟刪除（標記 isKicked=true），保留紀錄以利後續舉證，但不再有實際存取權。

保留期限屆滿後，我們將依《個人資料保護法》規定刪除或匿名化處理。

您的權利

依《個人資料保護法》第 3 條，您就我們持有之個人資料，得行使下列權利：

  • 查閱：請求查看您個人資料的內容；
  • 製給複本：請求提供個人資料之副本；
  • 補充或更正：對不正確或過時的資料請求修正；
  • 停止蒐集、處理或利用：請求終止後續處理；
  • 刪除：請求刪除您的個人資料。

Cookie 與追蹤技術

本平台使用 Cookie、LocalStorage 等技術以提升使用體驗，包括但不限於：

  • 記錄登入狀態（避免重複登入）；
  • 儲存車隊偏好設定（如語系、面板狀態）；
  • 儲存 LIFF SDK 必要參數（如 fleetId、liffId）。

我們不使用第三方廣告 Cookie，亦未進行跨站行為追蹤或廣告再行銷（remarketing）。您可隨時於瀏覽器設定中清除 Cookie，惟可能影響部分功能。

未成年人隱私

本平台主要服務對象為 18 歲以上之成年人。若您未滿 18 歲，請於法定代理人陪同並同意之情況下使用本服務。我們不會主動向未成年人蒐集個人資料；如發現未經法定代理人同意之未成年人資料，將依法盡速刪除。

國際資料傳輸

我們所有的核心資料儲存均位於台灣機房（Google Firebase asia-east1），未進行境外傳輸。然而，下列情境可能涉及第三方服務商之國際處理：

  • LINE Platform（總公司位於日本）處理推播訊息；
  • Telegram（如使用）位於境外伺服器；
  • Google Maps API 之地理查詢可能跨區處理。

上述第三方服務商均為國際大型雲端服務商，依其各自隱私政策遵守 GDPR、APPI 等國際資料保護規範。

我們可能因法令變動、業務調整、技術改進等原因修訂本政策。修訂時將於本平台公告或以電子郵件通知，並更新本頁「最後更新日期」。重大變更（如新增蒐集目的、新增分享對象）將取得您的明示同意。

建議您定期檢視本頁面以掌握最新政策。
