定義

為使本條款各條文意義明確，特定義如下：

  • 本平台 / 本服務：指 Rovia Airport 機場接送預約系統，含管理後台（Hub）、車隊後台、乘客 LINE LIFF、司機 LINE LIFF 等子應用。
  • 車隊：指與我們簽訂 SaaS 服務契約、取得車隊後台使用權、實際提供機場接送運送服務之合法營業計程車隊或運輸業者。
  • 司機：指經車隊招募、透過車隊碼加入車隊、實際駕駛車輛提供運送服務之自然人。
  • 乘客：指透過本平台向車隊預約機場接送服務之終端使用者。
  • 訂單：指乘客透過本平台預約並由車隊或司機接受之單次運送服務契約。
  • 車隊碼：指車隊用以邀請司機加入之專屬識別碼。
  • LIFF：指 LINE Front-end Framework，本平台之乘客端與司機端介面均建構於此技術上。

服務說明

本平台為車隊提供下列功能之軟體即服務（SaaS）：

  1. 乘客預約叫車介面（LINE LIFF，無需另行下載 App）；
  2. 車隊後台（含計費設定、車型管理、訂單管理、報表、推播通知範本等）；
  3. 司機端介面（接單、未完成訂單、紀錄、設定）；
  4. 派單系統（搶單、自動派、手動派三種模式）；
  5. LINE Flex 與 Telegram 雙通道訊息推播；
  6. 多種計費模式（公里計費、行政區固定價、階梯跳表、分段費率）；
  7. 積點與優惠券系統；
  8. 多機場據點管理（桃園 TPE、松山 TSA、台中 RMQ、高雄 KHH、基隆 KEL）。
重要說明

本平台僅為車隊與乘客之間提供資訊媒合與管理工具，實際運送服務由車隊獨立提供。我們不擁有車輛、不僱用司機、不直接從事運輸業。

4.2 車隊與乘客（運送契約）

4.3 我們與乘客（資訊技術服務）

我們不從事運輸業、不擁有車輛、不僱用司機、不收取車資、不直接受理運送投訴。乘客因運送服務本身所生之爭議，應向實際提供運送服務之車隊主張權利。我們僅就平台之資訊技術服務（如帳號、推播、訂單建立介面）負責，相關責任以本條款第 12 條之規範為準。

訂單規則

5.1 訂單類型

  • 即時叫車：乘客當下提交訂單，車隊立即處理；
  • 預約叫車：乘客指定未來日期與時間，由系統依車隊設定時間自動或手動派單。

5.2 派單模式

各車隊可自由設定派單模式：搶單（司機自由接）、自動派（系統輪派）、手動派（車隊客服指派）。乘客送出訂單後，視車隊設定進入對應流程。

5.3 訂單成立

訂單於司機接受並由系統發出「司機已接單」通知時成立。在此之前訂單視為「等待配對中」，乘客或車隊可隨時取消。

5.4 多點下車與緊急加值

若車隊有開放，乘客可選擇加入多個下車點或選擇緊急接送，相關費用以車隊預先設定為準，並於下單時顯示於費用明細。

計費與付款

6.1 訂單車資

訂單車資由車隊依其於本平台後台所設定之計費模式自動計算。費用包含但不限於：基本費、距離費、車型加成、時段加成、假日加成、加值服務、多點下車費等。乘客於下單時可預覽預估金額。

6.2 計費模式

  • 公里計費：基本費 + 每公里費率 × 距離；
  • 行政區固定價：機場到指定行政區之固定金額；
  • 階梯跳表：類似計程車跳錶，每段固定加金額；
  • 分段費率：多階段每公里費率，超過末段以末段費率延伸。

6.3 SaaS 月費

車隊使用本平台須依其選擇之方案，按月或依約定週期支付月費予我們。月費不含 LINE 官方推播費用、Google Maps API 費用、第三方支付手續費等其他費用，相關規則於車隊合作合約中另行訂定。

6.4 訂單金流歸屬

訂單車資直接屬於提供運送服務之車隊，本平台不經手乘客付給車隊之車資、不從中抽成。

7.1 乘客取消

乘客可在訂單尚未配對到司機前自由取消。司機已接單後之取消，可能依車隊設定收取取消費用，相關規則於下單時或車隊條款中揭露。

7.2 車隊或司機取消

因車隊或司機因素導致訂單取消，乘客不負擔任何費用；若已預付，車隊應全額退還。

7.3 系統異常

若因本平台系統異常致訂單無法執行，我們將協助車隊與乘客處理，但相關運送補償義務仍由車隊與乘客依運送契約處理。
